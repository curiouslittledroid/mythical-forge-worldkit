# The Atlas

**Summary:** How a world's map is kept true. Place notes are canon; the map data in `maps/` is
authored and everything else is generated from it. A change to a place becomes a small, readable
diff in three files, and **no rendered file is ever hand-edited**.

**This is the kit's mechanism.** A world owns its atlas: its frame, its sheets, its drawing rules,
its feature list and its history. What is fixed here is the pipeline, the data schema and the
rule that a rendered file is never edited.

## What is authored and what is generated

| File | Authored or generated | Hand-edit? |
|---|---|---|
| a place note in `world/` | **canon** | yes — this is where a fact lives |
| `maps/atlas-features.yaml` | **authored map data** | yes — one entry per feature |
| `maps/atlas-features.md` | generated by `tools/atlas_tables.py` | **no** |
| `maps/svg/*.svg`, `maps/svg/preview/*.png` | generated by the world's own `tools/local/make_atlas.py` | **no** |
| the world's map register / brief | authored | yes |

**One authority chain: notes → YAML → generated files.** If a coordinate is wrong, decide *where* it
is wrong: if the **note** is wrong, fix the note (a canon change); if only the **map position** is
wrong, fix the YAML. Never fix a rendered file — the next run overwrites it.

Nothing needs installing: the Python tools are standard library only. The preview renderer needs
macOS and Chrome at a standard path; that is why it is optional and why the previews are committed.

## The four commands

From the repository root:

```bash
python3 tools/atlas_yaml.py maps/atlas-features.yaml   # 1. validate: schema, ids, refs, geometry
python3 tools/atlas_tables.py                          # 2. render maps/atlas-features.md
python3 tools/local/make_atlas.py                      # 3. render the world's SVGs
python3 tools/atlas_diff.py                            # 4. what changed, and where
tools/atlas_previews.sh                                # optional: PNG previews (macOS + Chrome)
```

| Tool | What it does | Flags / exit codes |
|---|---|---|
| `tools/atlas_yaml.py` | Reads and validates the YAML. Prints `ok: 18 sections, 166 entries`, or `INVALID …` with the first problem. | exit 1 on any schema error |
| `tools/atlas_tables.py` | Writes `maps/atlas-features.md` from the YAML. | `--check` writes nothing and exits 1 if the file is stale |
| **`tools/local/make_atlas.py`** | Writes `maps/svg/*.svg`. **The world's, never the kit's** (D16): label placement, the frame layout and the map title are world choices. The sync never touches `tools/local/`. | — |
| `tools/atlas_diff.py` | Compares the YAML with a baseline and prints added, removed, moved and changed features. | `--check` exits 1 if anything changed; `--section cities` narrows; a path argument sets the baseline |
| `tools/atlas_previews.sh` | Renders `maps/svg/preview/*.png`. | needs Chrome at the standard macOS path |
| `tools/lint.py` | The vault linter. Run it after any edit to notes. | must be 0 errors |

A healthy run:

```text
$ python3 tools/atlas_yaml.py maps/atlas-features.yaml
ok: 18 sections, 166 entries
$ python3 tools/atlas_tables.py --check
…/maps/atlas-features.md is up to date
$ python3 tools/atlas_diff.py
no changes against the baseline
```

## Comparing two versions

Cheapest first:

```bash
git diff maps/atlas-features.yaml      # the raw change
git diff --stat HEAD~1                 # which generated files moved with it
python3 tools/atlas_diff.py            # the readable change
```

`atlas_diff.py` compares against `HEAD` by default, or against any file you pass — an older copy, a
tag, a colleague's branch:

```bash
git show HEAD~3:maps/atlas-features.yaml > /tmp/old.yaml
python3 tools/atlas_diff.py /tmp/old.yaml
```

## The data

`maps/atlas-features.yaml` is the authored layer: sections, entries, coordinates, the feature's
`id` (which must match a note's), and its class. `tools/atlas_yaml.py` owns the schema and validates
it; the atlas it describes is the world's. Keep ids stable across a move — a moved feature keeps its
id and changes its coordinates, so `atlas_diff.py` reports a **move** rather than a removal and an
addition, and the note keeps pointing at one feature.

## What a world supplies

| Thing | Where |
|---|---|
| the frame, the sheets, the drawing rules, the corrections history | the world's own map register note |
| the feature data | `maps/atlas-features.yaml` |
| its own renderer | `tools/local/make_atlas.py` (**world-owned**, never synced) |
| the previews | `maps/svg/preview/*.png` — committed, because they are not reproducible without macOS and Chrome |

A world that does not want a map leaves `atlas` out of its `features:` list and nothing here runs.
