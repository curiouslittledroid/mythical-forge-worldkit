# Regions

**Purpose:** The map's areas: each note is a region a campaign can be set in, with its magic class,
its climate now, and who claims it.

A **starting region** is the one the campaigns begin in, and the tools want it by id when a campaign
declares its zone. Write it first; the rest can wait.
