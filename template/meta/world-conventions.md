# World Conventions

**Summary:** The world's decisions **on top of** the kit's rules. **The rules themselves are the
worldkit's `docs/conventions.md`**, vendored at `tools/docs/conventions.md`: the id grammar,
frontmatter, the note body, blocks, disclosure, engagement, ids and filenames. Cite it by section
number ("the worldkit's `docs/conventions.md` §9.6"); never by wikilink.

This note holds only what is this world's:

## Decisions

- **Spelling:** the kit's metric (km) is law; spelling is a setting. This world uses `REPLACE`
  (`british` | `american` | `off`) in `world.config.yaml`'s `vault.spelling`.
- **The five-fold things:** `REPLACE` — every world decides its own short lists: the magic classes,
  the kinds of place, the ranks of its powers. Write them here and apply them everywhere.
- **What a note kind means here:** `REPLACE`, only where this world reads the kit's kind differently
  (usually: nothing).
