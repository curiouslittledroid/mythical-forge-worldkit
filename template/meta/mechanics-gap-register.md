# Mechanics Gap Register

**Summary:** Every mechanic this world needs that the engine cannot express — the M-numbers — with
what it blocks and what the workaround is. **This file is a request log, not a catalogue**: what the
engine can do, and which of these entries became platform requests, is the kit owner's business and
is not published into worlds.

**How to use it:** a note that wants a relationship kind, flag, effect, tactic or content descriptor
the engine does not have **logs it here** and uses the workaround. Never invent one in an `engine`
block: the closed vocabularies stay closed. The kit's `conventions.md` section 9.6 has the
rule.
