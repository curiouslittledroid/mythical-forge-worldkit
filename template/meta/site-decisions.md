# Site Decisions

**Summary:** The site's vocabularies: which tags earn an index page, which words must never appear on
a public page, which thread names are ordinary vocabulary rather than a spoiler, and the tone lines a
reader sees. The mechanism is the kit's `meta/conventions/site.md` section 3.3.

```site-vocabulary
published_tags: [REPLACE]

keystones: []

plot_web_surfaces: []
```

## Questions

1. **Which tags earn an index page?** A tag with an index page promises a reader a theme. Twelve to
   twenty is a browsable set; sixty is a maze.
2. **Which secrets must never be published?** The keystones: the truths that, printed, spoil the
   world. A keystone is named here so the exporter can hold it back.
3. **Which thread names may appear as plain words?** A plot-web name that is ordinary vocabulary is
   safe; a name that is only the plot is not.
