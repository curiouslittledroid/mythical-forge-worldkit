# Maps

**Purpose:** The world's maps: which plates exist, and what they are for. The method — the atlas
pipeline, the feature register, the commands that draw a sheet — is the worldkit's `docs/atlas.md`.

## The layout

- `maps/atlas-register.md` — the frame rules, the sheet plan, the corrections history
- `maps/atlas-features.yaml` — the authored map data: one entry per feature
- `maps/svg/` — the drawn sheets
- `maps/geography-data.yaml` — the world's own numbers, used by the tools that are the world's
